# Portfolio Refinement Direction

## FORM

seed-key: incumbent-signal-system / contained-to-expanded

## Mode

Experience — the visitor should understand Felix's operating philosophy through the interface itself.

## World

Preserve the monochrome Signal / System identity, but make it more typographically assured and less spatially loose. Nohemi carries the display voice; Instrument Sans handles reading; IBM Plex Mono is reserved for measured system metadata. Spectral color appears only as refracted light or progress feedback.

## First Viewport

At 1900×944 and common laptop sizes, the navigation, complete value proposition, supporting statement, both primary actions, contact placeholders, workflow map, and process ticker must fit without scrolling. A 300-particle WebGL field should be clearly perceptible but subordinate to the copy.

## Visitor Path

The compact hero establishes the promise. The About section changes the page's physical scale as a contained operating statement expands into a full viewport and reveals Felix's method. Skills, projects, proof, experience, and contact retain the existing information sequence and become part of the Nohemi-led system.

## Signature Interaction

The About section is a scroll-controlled expansion: a contained black field opens to the viewport while the statement settles into position and the explanatory content enters. The navigation's two-pixel line gives continuous, spring-smoothed document completion feedback.

## Quality Bar

- No clipped display type at any stage of the About expansion.
- Hero copy and CTAs remain inside the first viewport.
- Particle animation stays GPU-bound and stops for reduced motion.
- Reduced-motion users receive a fully expanded, readable About section.
- Mobile keeps the same narrative without the secondary workflow diagram competing for space.
